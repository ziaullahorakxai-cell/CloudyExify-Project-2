Project Overview

This project is a Student Management System developed in Python. It is a command-line application that helps manage student records efficiently. The program stores student information in a CSV file, allowing data to remain available even after the application is closed.

The system automatically calculates students' average marks, assigns grades, ranks students based on performance, and provides options to search, edit, and delete records.

---

Features

- Add new student records
- View all students
- Search student by ID
- Edit student marks
- Calculate average marks
- Automatically assign grades
- Rank students according to average marks
- Delete student records
- Save data into CSV file
- Load saved data automatically

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

5. Use the menu to manage student records.
